# Smart European Trip Architect

Курсовий проєкт з дисципліни «Інженерія програмного забезпечення».

Консольна програма на C# (.NET 8), яка розраховує час, вартість і викиди CO2
для поїздки містом (Лісабон, Дублін) з урахуванням типу маршруту
(найшвидший, мальовничий, бюджетний, екологічний) та додаткових опцій
(страховка, аудіогід, камера схову багажу).

Історія комітів відображає еволюцію рішення: від початкової реалізації
з умовною логікою в одному методі до архітектури з патернами
**Strategy** та **Decorator**.

## Структура

- `SmartTripArchitect/Routes` – стратегії розрахунку маршруту (Strategy)
- `SmartTripArchitect/Trip` – базова поїздка та опції-декоратори (Decorator)
- `SmartTripArchitect/Cities` – тарифи міст
- `SmartTripArchitect.Tests` – модульні тести MSTest
- `docs/class-diagram.png` – діаграма класів фінальної версії

## Запуск

Відкрити `SmartTripArchitect.sln` у Visual Studio 2022, запустити проєкт
`SmartTripArchitect` (Ctrl+F5). Тести – через Test Explorer.
